1
Type of elements:
My IntArray class stores primitive int values because it uses an int[] array.
Java's ArrayList is generic and stores elements of reference types, such as
Integer in an ArrayList<Integer>. Generics do not use primitive types directly, so
int values are represented by Integer objects when used with ArrayList<Integer>.

2
Available methods:
My IntArray class only provides the methods specifically implemented for this assignment,
such as get, set, insert, addToEnd, addToStart, and remove. Java's ArrayList implements
the List interface and provides many additional operations, such as contains, and indexOf.

3
Array and capacity management:
My IntArray class directly uses an int[] array and a count field, and my code is responsible
for creating a larger array and copying the elements when the array is full. Java's ArrayList
is also a resizable-array implementation, but its managed internally. Oracle's documentation
also provides methods such as ensureCapacity and trimToSize for managing ArrayList capacity.
